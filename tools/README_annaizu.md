# 集合場所案内図 — 使い方

現場ごとの「集合場所案内図」をA4横1枚で作る。業者さんへLINE/メールで送る前提。

- 本体: `genba-navi/annaizu_preview.html`（ダブルクリックでブラウザが開く。インストール不要）
- 地図生成: `genba-navi/tools/make_map_svg.py`

---

## 1. いちばん短い手順

1. `annaizu_preview.html` を開く
2. **地図を入れる**（下の3通りのどれか）
3. 「★ 集合マーカー」を押して、**地図の上でドラッグ**して集合場所へ置く
4. 左側で日時・参加者・注記を打つ
5. 「🖨 印刷 / PDF」→ PDF保存、または「🖼 PNG」→ LINEで送る
6. 「💾 再編集用に保存」で HTML を案件フォルダへ。**後日その HTML を「📂 読込」に投げれば続きから直せる**

---

## 2. 地図の入れ方（3通り）

### A. Claudeに作ってもらう（いちばんきれい・推奨）

Googleマップで集合場所を右クリック →「33.194743, 131.657121」をコピーして、Claudeに

> この座標で案内図用の地図SVGを作って： 33.194743, 131.657121

と頼む。裏で下記が動く。

```bash
python "C:\Users\user\artrays\claude ai\genba-navi\tools\make_map_svg.py" 33.194743 131.657121 --range 240 --out map.svg
```

- `--range` は図の高さの半分(m)。**敷地1つなら200〜260／街区ごと入れるなら400〜600**
- 建物・道路・駐車場・施設名に加えて、**縮尺バーと方位(N)もSVGに焼き込まれる**
- できた `map.svg` をアプリの「🖼 地図を読込（SVG / 画像）」にドロップ

Overpass が混んでいると失敗する（504）。数分後に再実行するか、下記Bで代用。
一度取れたJSONは `--save-json` で残しておけば `--from-json` で作り直せる。

### B. 画像を貼る（速い）

Googleマップのスクショ・施設の館内図・航空写真・手書き図を、ドロップか **Ctrl+V** で貼る。
※ この場合、縮尺バーは付かない（実距離が分からないため。誤った縮尺は出さない方針）。

### C. アプリ内の「自動生成を試す」

同じことをブラウザからやる。環境によってはブロックされる（その時はAかBへ）。

## 3. 目印

| 種類 | 使い方 |
|---|---|
| ★ 集合マーカー | 赤い二重丸＋文字。**地図の上でドラッグ**して移動。文字は左欄で編集 |
| ➜ 矢印 | **両端それぞれをドラッグ**して向きと長さを決める |
| あ 文字 | 「◯◯側」「搬入口」など。白フチ付きなので地図の上でも読める |

大きさは各行のスライダー。要らなくなったら「×」。

## 4. 拡大図

メイン地図の一部をそのまま拡大して右側に出す。**別の画像は要らない。**
拡大したい場所は**拡大図の中をドラッグ**、倍率は左欄のスライダー。要らなければチェックを外す。

---

## 5. 決めごと（印刷まわり）

- A4横・`@page margin 5mm`。余白0だと外周枠が印刷で切れるため。
- 文字は黒 `#000` 基準、グレーは `#666` が下限。
- 実寸：地図ラベル 10pt=3.53mm／カード本文 10.5pt=3.70mm／注記 11.5pt=4.06mm
  （JIS Z 8313 の漢字3.5mm・注記4mm以上を満たす）
- 注記が多いと自動で少しずつ文字を詰める。**最小(10pt)まで落ちると左欄に警告が出る**ので、
  そのときは1行を短くするか行数を減らす。
- 業者・社内向けの実務図。**案件キー・単価は載せない**。

## 6. ファイルの置き場所

案件フォルダの `工程\` に置く。

```
工程\
  集合場所案内図_YYYYMMDD_○○前.pdf              ← 印刷・送付用
  集合場所案内図_YYYYMMDD_○○前.png              ← LINE送付用
  集合場所案内図_YYYYMMDD_○○前_編集データ.json   ← 「📂 読込」で続きから直せる
  集合場所案内図_YYYYMMDD_地図.svg                ← 地図だけ（作り直し用）
```

---

## 実例

`AR-2026\ワラワ\ワラワ-パークプレイス店-26\工程\` に 2026/8/4 の一式が入っている。
`..._編集データ.json` を「📂 読込」に投げると、その状態から編集できる。
