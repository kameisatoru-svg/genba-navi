# リポジトリ差分ダイジェスト

このリポジトリは auto-push が動いていて、**コミットメッセージが全部 `auto-push`**。
`git log` を見ても何が起きたか一切わからない。
そこで**コミットメッセージではなく差分そのもの**から、期間の変更を要約する。

## 手順

### 1. 期間を決める
指定が無ければ**直近7日**。「先月」なら月初〜月末。

### 2. 変更のあったファイルを集計する
```bash
git --no-pager log --since="7 days ago" --name-only --pretty=format: \
  | sed '/^$/d' | sort | uniq -c | sort -rn | head -40
```

### 3. 実際の差分を読む
件数の多いファイル・重要なファイルを上から見る。
```bash
git --no-pager diff "@{7 days ago}" -- <ファイル>
```

`data.json` は巨大なので全文 diff を読まない。代わりに構造で見る：
```bash
git --no-pager diff --stat "@{7 days ago}" -- data.json
```
中身の変化を知りたいときは `artrays-data` MCP で現在値を読む。

### 4. 要約する

**ファイル名の羅列ではなく、業務の言葉で書く。**

- ✗「dashboard.html が 12回変更」
- ○「ステータス看板に『最近の動き』欄を追加し、財務イベント以外も出るようにした」

分類の目安：
| 区分 | 例 |
|---|---|
| アプリの機能 | 看板・ワークフロー・見積・図面・割付・台帳 |
| データ | 案件の追加/完了、取引先の登録、原価の反映 |
| 見た目 | common.css、印刷レイアウト |
| 仕組み | MCP、フック、スキル、`.gitignore` |

### 5. 出力

- 冒頭に**3行以内の総括**
- 続けて区分ごとに箇条書き
- 最後に「気になる点」（壊れかけ・やりかけ・整合が取れていないもの）

## 注意

- **公開リポジトリなので、要約をどこに書くかに注意する。**
  原価・単価・取引先の内情を含む要約を、リポジトリ内のファイルに書かない
- 出力先の指定が無ければ**チャットに出すだけ**にする。ファイルを勝手に作らない
- data.json の中身（金額・氏名）を要約に転記しない。件数や案件キーまでに留める
